MPS · STUDIO DE VENTE

Vos premiers clients virtuels.
Prêts à être essayés.

Trois profils, des personnages 3D animés et vos scénarios de vente. Commencez par la démonstration ; installez ensuite l’entretien IA sur Cloudflare.

Ouvrir la démonstration →Guide complet
1

Essayez sans rien installer

Ouvrez la démonstration dans un navigateur, choisissez Marc, Sophie ou Karim, puis cliquez sur « Commencer l’entretien ». Vous pouvez écrire au clavier. Les réponses de cette démonstration sont prédéfinies et ne donnent pas de note.

La voix dépend de votre appareil. Testez le micro sur le site HTTPS après l’installation.

2

Placez le dossier dans GitHub

Créez un dépôt privé et ajoutez le contenu du dossier décompressé. Il faut voir package.json et wrangler.jsonc à la racine du dépôt, avec les dossiers src et server. Ne déposez pas seulement le ZIP.

Conservez les fichiers de configuration et le fichier pnpm-lock.yaml. Aucune vraie clé API ne doit figurer dans GitHub.

3

Connectez GitHub à Cloudflare Workers

Créez un Worker à partir de votre dépôt GitHub. Utilisez ces réglages :

Nom du Workermps-simulateur-avatars
Répertoire racineRacine du dépôt
Build commandpnpm run test && pnpm run build
Deploy commandpnpm exec wrangler deploy
Variables de buildNODE_VERSION = 24
PNPM_VERSION = 11.19.0
4

Activez les conversations IA

Dans les variables et secrets d’exécution de votre Worker, ajoutez :

  • ANTHROPIC_API_KEY : votre clé API Anthropic.
  • ACCESS_CODE : un code de session que vous choisissez et donnez aux participants.

Appliquez les changements. Ouvrez l’adresse HTTPS du site, sélectionnez « Entretien avec l’IA », saisissez votre code et commencez. Les réponses et le débriefing utilisent votre API Anthropic.

Ce premier livrable est un pilote.

Les personnages sont réellement en 3D et animés, avec un rendu plus simple que votre référence. La bouche suit un rythme de parole approximatif, sans synchronisation phonétique précise.

21 tests automatiques et la compilation ont réussi. Le paquet Cloudflare a passé sa vérification de préparation. Le rendu visuel, le micro et la voix n’ont pas pu être testés dans un navigateur : le contrôle de sécurité de l’outil était indisponible. La conversation IA réelle reste à vérifier après saisie de votre clé.

Les sessions ne sont pas sauvegardées automatiquement. Utilisez l’export de l’entretien avant de recommencer.
